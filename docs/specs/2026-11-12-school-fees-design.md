# 私校学费数据层 — 设计文档

- **日期**: 2026-11-12
- **范围**: 新州非公立学校的学费（先做悉尼带中学的私校，加上悉尼、帕拉马塔两个天主教教区的全部学校），以及试点 31 所的招生和考试信息
- **状态**: 数据已抓取并校验，还没有接入页面

## 1. 为什么做

学校页要回答家长最关心的三件事：能不能进、多少钱、成绩如何。公立学校的“能不能进”靠学区边界已经能答；私校的“多少钱”是空白，`schools.canonical.json` 里 3,794 所私校一条学费都没有。2026-11-10 的 Search Console 分析显示，入学考试和学费相关的搜索落在私校学校页上，排名 35–55，点击为 0。

## 2. 数据放在哪

| 文件 | 进 git | 内容 |
|---|---|---|
| `data/fees/processed/fees.json` | 是 | 状态表兼数据表，每所尝试过的学校一条 |
| `data/fees/raw/<acara_sml_id>/` | 否 | 抓回来的网页和 PDF 文本，供提取和核对 |
| `data/fees/raw/_scs/`、`_cspd/` | 否 | 两个教区统一来源的原始响应 |

用 git 里的 JSON，不用数据库：项目运行时就没有数据库，学费只在构建时用，放在 git 里每次更新都能看到哪些学校的状态变了。

**表里没有的学校 = 还没尝试过。** 这和“尝试过但拿不到”是两件事，所以每次尝试不论结果都要留一条记录。

## 3. 状态

| 状态 | 含义 | 以后能补吗 |
|---|---|---|
| `found` | 从学校或其教育系统公布的来源读到了金额 | 每年重抓 |
| `fetched` | 页面已抓回，还没读数（中间状态） | 读数 |
| `not_published` | 网站写明学费需另行索取，或只列出申请费 | 基本不能 |
| `not_found` | 抓到的页面里没有学费 | 换入口再试 |
| `not_extracted` | 有学费，但读不出来（脚本渲染的表、图片 PDF、只给每学期金额且没写学期数、年份无法对应） | 用浏览器渲染或 OCR |
| `blocked` | 网站拒绝程序访问（403） | 手工或换方式 |
| `unreachable` | 网站连不上；`crawl.home_error` 记录原因 | 多半是 ACARA 里的网址过期，补网址 |
| `no_website` | ACARA 记录里没有网址 | 补网址 |

## 4. 怎么记金额

规则延续数据原则第 1 条和第 6 条：宁可空着，也不能写错；不能凭空制造精度。

- **照抄，不加总。** 学费表里的数字原样记录。只有学校自己公布了合计时才填 `total`，`basis` 用一句话写明这个数包含什么。其他必缴项目写进 `other_compulsory`。
- **年份必须有原文依据。** `fee_year` 取页面或文件标题上的年份。页面上有当期金额却没写年份时，`fee_year` 记为 `null`，并在 `year_note` 里写上“页面未写年份”和查看日期。只有更早年份（例如 2022）的学校不收录。
- **只公布每学期金额的学校，**只有写明了一年几个学期才记 `per_term` 和 `terms`，年费留给页面计算。没写学期数的记为 `not_extracted`，原数放在备注里。
- **本地生和国际生分两张表的，只记本地生那张；**分档收费的（例如 Lycée Condorcet），记澳洲居民那一档，并在 `basis` 里写明。
- `source`：`school_website`、`scs_endpoint`（悉尼天主教教区）、`diocese_schedule`（帕拉马塔等教区的统一页面或文件）。

## 5. 来源与脚本

```bash
npm run fees:fetch -- --scope sydney-secondary   # 抓学校官网，每所最多 16 页，180 天内抓过的跳过
npm run fees:fetch:scs                           # 悉尼天主教教区：一个公开接口按学校代码返回分年级学费
node scripts/fetch-fees-cspd.mjs                 # 新州其余天主教学校：/enrolment/school-fees 的统一模板
npm run fees:cards -- --limit 20                 # 已抓未读的学校，按所打印学费表附近的原文片段
npm run fees:validate                            # 状态合法、年份合理、每个金额都能在原文里找到
```

- **悉尼天主教教区**：`<代码>.syd.catholic.edu.au` 的学费页从 `/wp-content/plugins/scs-school-fees/json.show-one.php?schoolCode=<代码>` 取数，返回第一到第四个孩子的全年合计。学费年份取自学校自己的学费页；页面上没写年份的，不导入。
- **帕拉马塔教区**：每个年级一块，含 “Diocesan Tuition Fee” 和 “Total”，页首写着 “Fees Payable at … for <年份>”。不符合这个模板的页面不处理，状态保持原样。
- **其余学校**：先抓，再由人读证据片段，把结果写进状态表。读数的结果要过校验：每个金额都必须能在该校原文里找到（允许 PDF 把数字拆碎，也允许只在表头写一次 “$”）。

## 6. 2026-11-12 的结果

悉尼带中学的私校共 295 所：

| | 学校数 | 拿到学费 | 比例 |
|---|---|---|---|
| 天主教 | 78 | 64 | 82% |
| 独立学校 | 217 | 95 | 44% |
| 合计 | 295 | 159 | 54% |
| 其中 ACARA 有网址的 | 235 | 159 | 68% |

没拿到的 136 所：60 所 ACARA 没有网址，30 所有学费但读不出来，31 所抓到的页面里没有学费，14 所拒绝访问或连不上，1 所不公布。

两个教区的统一来源另外覆盖了范围外的学校（主要是小学）：悉尼天主教教区 140 所，帕拉马塔模板 78 所。状态表里 `found` 一共 320 所。年份分布：2026 年 152 所，2027 年 161 所，2025 年 2 所，未写年份 5 所。

## 7. 维护

- 学校一般在 9–12 月公布下一年学费。每年 11 月到次年 1 月按 `fee_year` 重抓一遍：`fees:fetch` 用 `--stale-days` 控制范围，两个教区脚本整体重跑。
- 能提高覆盖率的三件事，按收益排：补 60 个缺失的网址；用浏览器渲染或 OCR 处理 30 所读不出来的；扩到新州其余带中学的私校（242 所）以及 Broken Bay、Wollongong 等教区的统一来源。
- 招生和考试信息目前只有试点 31 所，结构见 `fees.json` 里的 `admissions` 字段。
